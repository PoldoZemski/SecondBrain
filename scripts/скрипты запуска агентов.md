# скрипты запуска агентов

Заметка хранит скрипты запуска архивариуса, методиста, секретаря, библиотекаря и бизнес-аналитика. Каждый .sh относится к одному агенту и не зависит от других файлов. Скрипт без работы выходит за доли секунды и не вызывает Claude. Поэтому cron опрашивает агентов раз в час: это страховка к path-юнитам, а не замена им. Бизнес-аналитик работает отдельно, в каталоге /opt/second-brain/work, и опрашивается строкой в crontab пользователя brain каждые 15 минут (в cron.d его нет).

Что проверяет каждый скрипт:
- задания агенту в 06-inbox/tasks/: строка `for:` в начале строки, без `task_status: ждет решения`, поле `after` уже в 99-archive/tasks-done/;
- предложения агента в 06-inbox/proposals/ с решением «одобрено» или «отклонено», первая буква любого регистра;
- архивариус дополнительно: карточки идей, измененные после прошлой проверки и стоящие не на месте.

Один агент не запускается дважды одновременно: второй запуск выходит по блокировке flock.

## Установка на сервере

Команды выполняются от администратора. Скрипты извлекаются из этой заметки командой awk.

Шаг 1. Извлечь и проверить синтаксис:

```bash
NOTE="/opt/second-brain/vault/04-resources/guides/second-brain/scripts/скрипты запуска агентов.md"; for s in run-archivist run-methodologist run-secretary run-librarian; do sudo -u brain awk -v s="$s" '$0=="```bash " s ".sh"{f=1;next} /^```$/{f=0} f' "$NOTE" > /tmp/$s.sh; [ -s /tmp/$s.sh ] && bash -n /tmp/$s.sh && echo "OK $s" || echo "ОШИБКА $s"; done
```

Шаг 2. Сохранить старые версии и установить новые. Выполнять, только если шаг 1 дал четыре строки OK:

```bash
D=/opt/second-brain/automation/scripts; for s in run-archivist run-methodologist run-secretary run-librarian; do sudo -u brain cp -a $D/$s.sh $D/$s.sh.bak-1019; sudo install -o brain -g secondbrain -m 750 /tmp/$s.sh $D/$s.sh; done; ls -la $D
```

Шаг 3. Установить почасовой опрос:

```bash
NOTE="/opt/second-brain/vault/04-resources/guides/second-brain/scripts/скрипты запуска агентов.md"; sudo awk '$0=="```cron second-brain-agents"{f=1;next} /^```$/{f=0} f' "$NOTE" | sudo tee /etc/cron.d/second-brain-agents > /dev/null; sudo chmod 644 /etc/cron.d/second-brain-agents; cat /etc/cron.d/second-brain-agents
```

Шаг 4. Добавить аргумент `full` в строку библиотекаря в crontab пользователя brain: без него еженедельная полная проверка не выполняется, потому что скрипт без работы выходит сразу. Сначала сохраните копию crontab:

```bash
sudo -u brain crontab -l | sudo tee /tmp/crontab-brain.bak > /dev/null
sudo -u brain crontab -l | sed 's|run-librarian\.sh$|run-librarian.sh full|' | sudo -u brain crontab -
sudo -u brain crontab -l | grep librarian
```

Признак успеха: строка библиотекаря заканчивается словами `run-librarian.sh full`. Остальные строки crontab менять не нужно: параллельный запуск одного агента исключает блокировка flock.

Откат: `sudo -u brain cp -a <имя>.sh.bak-1019 <имя>.sh` в папке скриптов, `sudo rm /etc/cron.d/second-brain-agents` и `sudo -u brain crontab /tmp/crontab-brain.bak`.

## run-archivist.sh

Агент: архивариус.

```bash run-archivist.sh
#!/bin/bash
set -u
export LC_ALL=C.UTF-8
cd /opt/second-brain/vault || exit 1
set -a
. /home/brain/.env
set +a
export PATH=/home/brain/.npm-global/bin:$PATH
SCRIPTS=/opt/second-brain/automation/scripts
LOGS=/opt/second-brain/automation/logs
AGENT=архивариус

# Один экземпляр агента за раз. Второй запуск выходит сразу.
exec 9>/home/brain/.lock-archivist
flock -n 9 || exit 0

# Задания агенту, готовые к исполнению.
# Пропускает задания с task_status: ждет решения и задания, чье after еще не в архиве.
ready_tasks() {
  grep -rlE "^for:[[:space:]]*\"?$AGENT\"?[[:space:]]*$" 06-inbox/tasks/ 2>/dev/null |
  while IFS= read -r f; do
    grep -qE '^task_status:[[:space:]]*"?[Жж]д.{1,2}т решения' "$f" && continue
    dep=$(sed -n 's/^after:[[:space:]]*"\{0,1\}\[\[\([^]|]*\)\]\].*/\1/p' "$f" | head -n 1)
    if [ -n "$dep" ] && [ ! -f "99-archive/tasks-done/$dep.md" ]; then
      continue
    fi
    echo "$f"
  done
}

# Предложения агента с решением пользователя. Первая буква решения любого регистра.
decided_proposals() {
  grep -rlE "^from:[[:space:]]*\"?$AGENT\"?[[:space:]]*$" 06-inbox/proposals/ 2>/dev/null |
  while IFS= read -r f; do
    grep -qE '^proposal_status:[[:space:]]*"?([Оо]добрено|[Оо]тклонено)' "$f" && echo "$f"
  done
}

TASKS=$(ready_tasks)
PROPOSALS=$(decided_proposals)

STAMP=/home/brain/.last-run-archivist
ISTAMP=/home/brain/.last-ideas-archivist
[ -f "$STAMP" ] || touch "$STAMP"
[ -f "$ISTAMP" ] || touch -d '2000-01-01' "$ISTAMP"
# Метки следующего прогона ставятся до проверки: правка во время прогона не потеряется.
touch "$STAMP.next" "$ISTAMP.next"

# Карточки идей, измененные после прошлой проверки и, возможно, стоящие не на месте.
ideas_pending() {
  find 10-ideas -type f -name '*.md' ! -name index.md -newer "$ISTAMP" 2>/dev/null |
  while IFS= read -r f; do
    case "$f" in
      10-ideas/realised/*)
        grep -qE '^реализовано:[[:space:]]*"?нет' "$f" && echo "$f" ;;
      10-ideas/*/*)
        grep -qE '^реализовано:[[:space:]]*"?да|^\|[[:space:]]*стала[[:space:]]*\|' "$f" && echo "$f" ;;
      *)
        echo "$f" ;;
    esac
  done
}

NEW=$(find 06-inbox -type f -newer "$STAMP" 2>/dev/null | grep -vE '^06-inbox/(tasks|proposals)/')
IDEAS=$(ideas_pending)

if [ -z "$NEW$TASKS$PROPOSALS$IDEAS" ]; then
  mv -f "$STAMP.next" "$STAMP"
  mv -f "$ISTAMP.next" "$ISTAMP"
  exit 0
fi

echo "=== $(date '+%F %H:%M') ===" >> "$LOGS/архивариус.log"
"$SCRIPTS/vault-commit.sh" "до архивариуса"

claude -p "Карточка агента: $(cat '00-atlas/agents/архивариус.md')
Новые файлы: $NEW
Идеи к проверке: $IDEAS" \
  --model haiku \
  --allowedTools "Read,Glob,Grep,Write,Edit,Bash(mv:*),Bash(mkdir:*),Bash(touch:*),Bash(python3 /opt/second-brain/vault/00-atlas/agents/skills/naming-check/scripts/check-names.py:*)" \
  --permission-mode acceptEdits \
  >> "$LOGS/архивариус.log" 2>&1
RC=$?

if [ $RC -eq 0 ]; then
  mv -f "$STAMP.next" "$STAMP"
  mv -f "$ISTAMP.next" "$ISTAMP"
else
  rm -f "$STAMP.next" "$ISTAMP.next"
fi
"$SCRIPTS/vault-commit.sh" "после архивариуса"
```

## run-business-analyst.sh

Агент: бизнес-аналитик. Работает в каталоге /opt/second-brain/work, отдельном от хранилища: там данные третьих лиц. Работа есть, если в папке источников этапа лежит файл новее выжимки этапа или выжимки еще нет. Скрипт запрещает агенту читать хранилище, держит один экземпляр (прогон на модели sonnet может идти дольше 15 минут) и выдает агенту только инструменты чтения и записи без Bash.

```bash run-business-analyst.sh
#!/bin/bash
set -u
export LC_ALL=C.UTF-8
cd /opt/second-brain/work || exit 1
set -a
. /home/brain/.env
set +a
export PATH=/home/brain/.npm-global/bin:$PATH
LOG=/opt/second-brain/automation/logs/бизнес-аналитик.log

# Один экземпляр агента за раз. Второй запуск выходит сразу.
exec 9>/home/brain/.lock-business-analyst
flock -n 9 || exit 0

# Работа есть, если хоть один источник новее выжимки этапа
# или выжимки еще нет, а источники лежат.
NEW=""
for d in */*/источники; do
  [ -d "$d" ] || continue
  out="$(dirname "$d")/выжимка.md"
  if [ ! -f "$out" ]; then
    [ -n "$(ls -A "$d" 2>/dev/null)" ] && { NEW="$d"; break; }
  else
    [ -n "$(find "$d" -type f -newer "$out" 2>/dev/null)" ] && { NEW="$d"; break; }
  fi
done

if [ -z "$NEW" ]; then
  exit 0
fi

echo "=== $(date '+%F %H:%M') ===" >> "$LOG"

claude -p "Карточка агента: $(cat '/opt/second-brain/vault/00-atlas/agents/бизнес-аналитик.md')" \
  --model sonnet \
  --allowedTools "Read,Glob,Grep,Write,Edit" \
  --settings '{"permissions":{"deny":["Read(/opt/second-brain/vault/**)"]}}' \
  --permission-mode acceptEdits \
  >> "$LOG" 2>&1
```

Установка (от администратора), строка crontab с */15 уже стоит и менять ее не нужно:

```bash
NOTE="/opt/second-brain/vault/04-resources/guides/second-brain/scripts/скрипты запуска агентов.md"; s=run-business-analyst; sudo -u brain awk -v s="$s" '$0=="```bash " s ".sh"{f=1;next} /^```$/{f=0} f' "$NOTE" > /tmp/$s.sh; [ -s /tmp/$s.sh ] && bash -n /tmp/$s.sh && echo "OK $s" || echo "ОШИБКА $s"
```

```bash
D=/opt/second-brain/automation/scripts; s=run-business-analyst; sudo -u brain cp -a $D/$s.sh $D/$s.sh.bak-1019; sudo install -o brain -g secondbrain -m 750 /tmp/$s.sh $D/$s.sh; ls -l $D/$s.sh
```

Откат: `sudo -u brain cp -a /opt/second-brain/automation/scripts/run-business-analyst.sh.bak-1019 /opt/second-brain/automation/scripts/run-business-analyst.sh`.
