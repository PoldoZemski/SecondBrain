# Карточка идеи

Идея - замысел, еще не ставший проектом или продуктом. Карточка фиксирует замысел и его эволюцию.

## Расположение

Карточки лежат в тематических подпапках `10-ideas/<тема>/`. Папки по приоритету не заводятся. Новую тематическую подпапку создает архивариус по одобренному предложению о раскладке. Реализованные идеи лежат в `10-ideas/realised/` с той же тематической подпапкой.

Тема записывается дважды: подпапкой и строкой `касается | [[<тема>]]` в разделе «Связи». Название темы в папке и в связи совпадает.

Имя файла: нижний регистр, обычная «е» вместо «е» с двумя точками (`мобильное приложение дневника.md`).

## YAML

```yaml
---
type: идея
направление:
created: ГГГГ-ММ-ДД
source: откуда идея (встреча, статья, контакт)
status: гипотеза | проверено | решение
status_by: пользователь | агент
реализовано: нет
tags:
  - "идея"
---
```

Поле `реализовано`: «нет» по умолчанию, «да» ставит пользователь или архивариус, когда идея стала проектом, продуктом или процессом. Статус: гипотеза, затем проверено (обсуждено), затем решение (выбрано для реализации).

## Тело карточки

- Заголовок H1: название идеи, 5-10 слов.
- Первый абзац без подзаголовка: суть идеи, 2-3 предложения: что это, зачем, что дает. Конкретно.
- `## Следующие шаги`: `- [ ] #todo текст задачи` по CLAUDE.md. Шага нет: «нет ясного следующего шага» обычным текстом.
- `## Связи`: таблица по скиллу entity-relations, обязательна. Глаголы для идей: `возникла_из` (источник: встреча, статья, контакт, другая идея), `стала` (реализация: проект, продукт, процесс), `касается` (контекст и тема).
- `## История`: список, новое сверху, дата впереди (ДД.ММ.ГГГГ). Обязательна.

## Правило связи «стала»

Идея реализована, когда в «Связях» появляется строка `| стала | [[карточка проекта]] | дата начала |`. Архивариус по этой строке переносит карточку в `10-ideas/realised/`. В карточке проекта ставь обратную связь `возникла_из`.

## Правила

- Не правь другие карточки при создании идеи: нормализацию делает архивариус отдельным заданием.
- Указывай источник идеи в поле source.
