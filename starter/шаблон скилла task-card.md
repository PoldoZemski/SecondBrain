# Карточка задания для агента

## Имя файла и расположение

Файл задания лежит в папке `06-inbox/tasks/`. Имя описывает суть задания, нижний регистр, 20-60 символов. Примеры: `разобрать входящие за неделю.md`, `создать карточку контакта иванов иван.md`.

## YAML-шапка

```yaml
---
type: task
for: <имя агента>
created: ГГГГ-ММ-ДД
task_status: к исполнению
tags:
  - "task"
source: мое решение
---
```

Обязательные поля:
- `type: task` - ровно это значение.
- `for: <имя агента>` - кому задание. Только русское имя из раздела «Роль» карточки агента, без латинского имени.
- `created: ГГГГ-ММ-ДД` - дата создания.
- `task_status: к исполнению | ждет решения | выполнено`. `к исполнению` - готово к работе. `ждет решения` - пауза до решения пользователя, агент задание пропускает.
- `tags`, `source` - по скиллу yaml-frontmatter.

Поле `after: [[имя другого задания]]` (необязательное): агент не возьмется за задание, пока указанное не перемещено в 99-archive/tasks-done/.

## Содержание задания

После YAML-блока идет содержание.

- Раздел «Задание»: описание работы 2-4 предложениями, четкая цель, что обрабатывать, в каких папках.
- Раздел «Как проверить результат»: конкретные команды проверки (grep, find, подсчет файлов) и что должно получиться. Агент выполняет их перед отчетом.
- Для массовых заданий: раздел «На сколько элементов рассчитано», раздел «Файл отслеживания» (путь и формат строк прогресса), раздел «Что делать с ошибками» (три попытки, затем пропустить и вынести в отчет).
- Если задание опирается на скилл: раздел «Версия скилла» с именем и версией из metadata.version.

Формулируй массовое задание как «обработай необработанное», а не «обработай партию из N»: агент работает самовозобновляемо.

## Чек-лист

- [ ] Имя файла ясно описывает задание.
- [ ] Есть YAML-блок с `type: task` и `for: <имя>`.
- [ ] Есть раздел «Как проверить результат» с конкретными командами.
- [ ] Для массового задания указаны файл отслеживания и правило для ошибок.
- [ ] Поле `task_status` установлено правильно.
- [ ] Огромное задание разбито на несколько файлов с разными целями.
