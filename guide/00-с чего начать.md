# 00. С чего начать

Эта серия заметок описывает «второй мозг»: записную книжку Obsidian на всех ваших устройствах плюс ИИ-помощники на вашем сервере. Начните здесь.

## Для кого

Для человека, который не знает, что такое ИИ-агент, и никогда не настраивал сервер на Linux. Программировать не нужно. Нужно уметь открыть терминал, скопировать команду, вставить ее и прочитать ответ. Если что-то не понятно с первого раза, это нормально: незнакомые слова собраны в [00-глоссарий](00-%D0%B3%D0%BB%D0%BE%D1%81%D1%81%D0%B0%D1%80%D0%B8%D0%B9.md).

## Чего этот гайд не делает

- Не учит основам Linux. Он дает готовые команды и объясняет, что они делают и какой результат ждать.
- Не заменяет документацию программ. Там, где нужна официальная документация, дана ссылка.

## Что вы получите

Простое объяснение без команд: [00-как это работает простыми словами](00-%D0%BA%D0%B0%D0%BA%20%D1%8D%D1%82%D0%BE%20%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%B0%D0%B5%D1%82%20%D0%BF%D1%80%D0%BE%D1%81%D1%82%D1%8B%D0%BC%D0%B8%20%D1%81%D0%BB%D0%BE%D0%B2%D0%B0%D0%BC%D0%B8.md). Прочитайте его первым.

## Что понадобится

| Что | Зачем | Что известно о цене |
|---|---|---|
| Виртуальный сервер (VPS) с Ubuntu 22.04 | Здесь живут синхронизация и агенты | Достаточно 4 vCore, 6 GB RAM и 100 GB SSD. Цена зависит от провайдера: смотрите на его сайте |
| Домен с возможностью создавать поддомены | Адреса сервисов, например sync.ваш-домен | Цена у регистратора |
| Obsidian | Записная книжка на ваших устройствах | Бесплатное приложение. Подписка Obsidian Sync не нужна |
| Ключ API Anthropic | Агенты работают через него | Оплата по токенам, отдельный счет. Расход зависит от модели: день активной отладки агентов на самой дорогой модели обошелся в 20 долларов. Выбирайте недорогую модель и сразу задайте месячный лимит трат в консоли |
| Компьютер, по желанию iPhone | Работа с заметками | Ноутбук с Windows или Mac и iPhone подходят |
| Канал к API через прокси | Только если сервер в стране, где доступ к API ИИ заблокирован | Добавляет заметный кусок работы, см. [05-claude code на сервере](05-claude%20code%20%D0%BD%D0%B0%20%D1%81%D0%B5%D1%80%D0%B2%D0%B5%D1%80%D0%B5.md) |

Идите по этапам: после каждого этапа есть чек-лист выхода, остановиться можно на любом.

## Как подключиться к серверу

Это общие сведения, они не зависят от провайдера. После заказа сервера провайдер присылает адрес (IP) и данные для входа. Откройте терминал: на Windows 10 и 11 это PowerShell, на Mac программа Terminal. Введите команду вида:

```bash
ssh root@АДРЕС_СЕРВЕРА
```

При первом подключении терминал спросит, доверять ли серверу. Ответьте yes. Пароль при вводе на экране не отображается, это нормально. Если провайдер дал ключ вместо пароля, следуйте его инструкции. Дальше гайд [01-подготовка vps и безопасность](01-%D0%BF%D0%BE%D0%B4%D0%B3%D0%BE%D1%82%D0%BE%D0%B2%D0%BA%D0%B0%20vps%20%D0%B8%20%D0%B1%D0%B5%D0%B7%D0%BE%D0%BF%D0%B0%D1%81%D0%BD%D0%BE%D1%81%D1%82%D1%8C.md) проведет вас по настройке.

## Имена в инструкциях

Во всех инструкциях используются одни и те же имена. Подставьте свои значения только там, где это сказано:

| Что | Значение в инструкциях |
|---|---|
| Администратор сервера | admin_name (замените на свое имя пользователя) |
| Пользователь агентов | brain (UID 1500), группа secondbrain (GID 1600) |
| Каталог системы | /opt/second-brain |
| Хранилище на сервере | /opt/second-brain/vault |
| Контейнеры | second-brain-couchdb, second-brain-bridge |
| Домен | example.com (замените на свой домен, например sync.example.com на sync.вашдомен.ru) |
| Файл ключей агентов | /home/brain/.env |

## Пометки в шагах

- **[сервер]**: шаг выполняется в терминале на сервере.
- **[obsidian]**: шаг выполняется в приложении Obsidian на любом устройстве.

## Правила безопасности для новичка

1. Не публикуйте сервис в интернете без пароля ни на день. См. [урок - публичные сервисы без auth](../lessons/%D1%83%D1%80%D0%BE%D0%BA%20-%20%D0%BF%D1%83%D0%B1%D0%BB%D0%B8%D1%87%D0%BD%D1%8B%D0%B5%20%D1%81%D0%B5%D1%80%D0%B2%D0%B8%D1%81%D1%8B%20%D0%B1%D0%B5%D0%B7%20auth.md).
2. Не отправляйте ключи, пароли и токены в чат с помощником-ИИ и в заметки. Если нужно показать вывод команды, закройте секреты символами.
3. Сначала задайте лимит трат в консоли, потом запускайте агентов.
4. Меняйте одну вещь за раз и после каждого изменения проверяйте результат по чек-листу.
5. Команды, которые что-то удаляют или меняют права на каталоги, выполняйте только понимая последствия.
6. Помощник-ИИ в чате не видит ваш сервер. Он знает только то, что вы ему прислали. Присылайте вывод команд, а не пересказ.
