# 09. Запуск Claude Code вручную

Предыдущая: [08-сторож синхронизации](08-%D1%81%D1%82%D0%BE%D1%80%D0%BE%D0%B6%20%D1%81%D0%B8%D0%BD%D1%85%D1%80%D0%BE%D0%BD%D0%B8%D0%B7%D0%B0%D1%86%D0%B8%D0%B8.md). Следующая: [10-как завести нового агента](10-%D0%BA%D0%B0%D0%BA%20%D0%B7%D0%B0%D0%B2%D0%B5%D1%81%D1%82%D0%B8%20%D0%BD%D0%BE%D0%B2%D0%BE%D0%B3%D0%BE%20%D0%B0%D0%B3%D0%B5%D0%BD%D1%82%D0%B0.md).

## Короткий ответ

Одной строкой, из любой оболочки:

```bash
sudo -u brain -H bash -lc 'set -a; . ~/.env; set +a; ~/.npm-global/bin/claude -p "вопрос" --model haiku'
```

Через оболочку, если команд несколько:

```bash
sudo -u brain -H bash -l
set -a; . ~/.env; set +a
cd /opt/second-brain/vault
~/.npm-global/bin/claude -p "вопрос" --model haiku
```

Выход из оболочки: команда `exit`.

## Почему нельзя просто вызвать claude

Три причины, каждая ломает запуск по отдельности:

- Пользователь. Claude Code установлен для brain. У администратора команды claude в PATH нет.
- PATH. sudo подставляет свой secure_path и не читает профиль пользователя, потому что не запускает login-оболочку. Отсюда «command not found» даже под brain. Решение: флаг -l у bash или полный путь ~/.npm-global/bin/claude.
- Ключ API. Он лежит в /home/brain/.env и сам в окружение не попадает. Агенты работают, потому что их скрипты загружают файл явно. При ручном запуске загрузите его сами: `set -a; . ~/.env; set +a`. Конструкция set -a экспортирует все переменные из файла, даже записанные без слова export.

## Правила внутри оболочки brain

- Не используйте sudo. У brain нет sudo и пароля: это часть защиты, учетная запись агентов не должна уметь повышать права. Свои файлы (~/.claude/, ~/.env) brain правит напрямую.
- Не запускайте команды из /home/admin_name. Домашний каталог закрыт правами 750, и команды вроде find падают с «Failed to change directory». Сначала выполните `cd /tmp` или перейдите в рабочий каталог.
- Всегда указывайте --model. По умолчанию берется самая мощная и дорогая модель, разница Opus и Haiku примерно двадцатикратная. Для проверок и коротких вопросов используйте haiku.

## Расшифровка ошибок

| Сообщение | Причина |
|---|---|
| command not found | PATH: нет -l у bash или неполный путь |
| Not logged in | ключ не в окружении или закончился баланс в консоли |
| Credit balance is too low | закончился баланс в консоли |
| Failed to change directory: /home/admin_name | запуск из чужого домашнего каталога |
| Not a directory | лишний слэш в конце имени файла |

«Not logged in» означает две разные вещи. Сначала проверьте окружение, потом баланс:

```bash
sudo -u brain -H bash -lc 'cut -d= -f1 ~/.env'
```

В списке должны быть ANTHROPIC_API_KEY и, если нужен прокси, HTTPS_PROXY.

Файл /home/brain/.claude/.credentials.json с содержимым {"mcpOAuth":{}} на аутентификацию Claude Code не влияет. Не ищите в нем причину ошибки «Not logged in».

## Интерактивная сессия

Запуск без -p открывает диалог. Каждое сообщение в нем - платный вызов. Используйте его, только когда нужна слэш-команда (/mcp, /plugin). Выход: /exit.

## Проверка, что агент работает прямо сейчас

```bash
pgrep -af claude
```

Команда выводит полную командную строку: по ней видно, какой агент запущен. Пустой вывод означает, что агентов нет.

Промпт агента виден в списке процессов любому пользователю системы. Не помещайте в карточку агента секреты и имена клиентов.
